Recipe Builder

About

Recipe Builder 1.0.0 makes the json of a Bedrock recipe: crafting, stonecutter, furnace, brewing and smithing. Nothing is uploaded.

Item icons are loaded from Mojang's public bedrock-samples repository and are not part of this page.

More tools: duskaraa.github.io

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.

Help

A recipe is one json file in the recipes folder of a behavior pack. It says which items, in which station, give which result.

The steps

  1. Station: where the recipe is made.
  2. Recipe: pick up an item below and click the slots of the board.
  3. Details: identifier, stations and recipe book. All filled in for you.
  4. Export: copy or download the json.

Mouse, touch and keys

  • Click an item to pick it up, then click slots to place it.
  • Drag a slot to move it. Ctrl + drag copies it. Drop it outside the board to clear it.
  • Right-click, double-click or Delete clears a slot.
  • Esc drops the item in your hand.
  • Open a recipe json with the top-right button, drop it on the page or paste its text.
  • Phone: tap a slot, then choose an item.

Problems

Click a problem to jump to it. Many have a fix button. The usual mistakes:

  • The result is empty.
  • An item id without a namespace, like stick instead of minecraft:stick.
  • Unlock with a format version older than 1.20.10.
  • The file is not in the recipes folder.

Good to know

  • Exact shape needs the same layout, any order does not.
  • A tag accepts any item of a group.
  • Data empty accepts any variant.
  • The 2x2 inventory grid uses the same recipes.
  • Custom furnace or brewing blocks are not possible.
  • Names, enchantments and NBT cannot be set on results.
  • Download pack gives a .mcpack with this recipe: open the file and Minecraft imports it, then turn it on in the Behavior Packs of your world.
  • Pack + source (.zip) holds that .mcpack plus the pack folder.
  • Your work is saved in this browser.
  • Icons come from GitHub. Nothing is uploaded.
